## 图纸怎么读

- 相同网络名表示电气相连，不必画一根跨整张纸的长线。例如U1.PA9与U4.RXD同为`RADIO_RX`。
- R是电阻，C是电容，U是芯片或成品模块，J是接口，JP是跳线，SW是开关。X表示不接；圆点表示导线电气连接。
- `GND_NODE`是采集节点地，`GND_RX`是电脑接收端地。两端通过无线联系，不需要拉一根线把两边的地连起来。
- 模块引脚按文字名称连接。模块方框不是可直接生成PCB的封装；不要把示意位置当成所有商品的实际针脚排列。
- J1/J2/J4/J5/J6是逻辑接口清单，不对应任意商品线束的统一物理脚序。SW1的1/2/3分别表示两个电源输入和公共输出，实际开关公共端须实测识别。
- `DNP`表示不装。ADXL345模块若已经有合适的3.3V上拉，R2/R3不重复装；先确认芯片实际电源和I/O电压。

## 与现有代码的对应

| MCU脚 | 图纸网络 | 用途 |
|---|---|---|
| PA0 | VSTORE_ADC | 100k+100k分压，倍率2 |
| PA1 | TEMP_DQ | DS18B20，4.7k上拉 |
| PB6/PB7 | I2C_SCL / I2C_SDA | ADXL345，CS高、SDO低，地址0x53 |
| PA9/PA10 | RADIO_RX / RADIO_TX | USART1：MCU TX接无线RX |
| PB0/PB1/PB10 | RADIO_M0 / RADIO_M1 / RADIO_AUX | 模式与握手 |
| PA2/PA3 | DBG_TX / DBG_RX | USART2调试，RX输入当前不处理命令 |
| PA13/PA14 | SWDIO / SWCLK | 保留SWD烧录调试 |

图纸生成器检查这些网络、收发交叉、ADXL地址选择、LDO引脚、两侧电源地分离及ADC倍率。校验连接表不等于EDA电气规则检查或真实接线测量。

## 电源页的范围

初期可以使用受控3.3V电源通过SW1外供电，分别验证主板、传感器和无线。也可用限流低压直流源模拟名义4.0V的VSTORE，单独检查LP5907稳压链。切换前确认电源和开关接法，不能把两路稳压输出并接。

LP5907仅按`LP5907MFX-3.3/NOPB`的SOT-23-5连接：1=IN，2=GND，3=EN，4=NC，5=OUT。其他封装不能套用。输入、输出2.2uF是名义值，必须保证偏压、温度和容差后仍满足至少1uF有效电容；无线bulk电容及稳压稳定性也须检查。[TI LP5907数据手册](https://www.ti.com/lit/ds/symlink/lp5907.pdf)

JP1为ADC测量跳线：先给节点供电，再接独立低压VSTORE；节点无电时断开该测量源，防止PA0倒灌。后续若用硬件欠压断开MCU电源，需要同时处理采样输入隔离，不能仅沿用当前跳线调试接法。

本版**没有画完磁芯、整流限压、降压、超级电容充电和硬件欠压的元件级电路**。最后一页虚线框是设计边界，不能按它直接焊接或把大电容直接并到任意降压板上。LMR36503的完整后缀、反馈/频率/UVLO、电感、保护阈值、最大输入、充电限流和泄放功率要按实际取能器核算。[TI LMR36503数据手册](https://www.ti.com/lit/ds/symlink/lmr36503.pdf)

参考作品PDF第10页给出了相似电源链与局部图，但没有提供全部取能参数。TVS型号中的电压不是它的最大钳位电压，不能只凭一个“64V”标记判断是否保护住后级。参考图的后缀、额定与实际工况需要重新验证，不照抄其性能结论。

## 文件清单与编辑方式

- PDF：看图和打印；SVG：可在矢量编辑器中改图，但不会自动做ERC或生成PCB。
- [BOM.csv](BOM.csv)：32项元件/模块与说明，包含可选项、去耦初值；不是完整取电系统采购清单。
- [Connections.csv](Connections.csv)：100项引脚到网络的映射，供人工核对或后续重建EDA图；不是KiCad原生网表。
- [schematic_scene.json](schematic_scene.json)：矢量几何和文字数据。
- [generate_schematic.py](generate_schematic.py)：同源生成PDF/SVG/连接表。依赖reportlab和pypdf，使用Windows微软雅黑；运行不会改固件。修改后要重新进行图面与电气核对。

当前未提供KiCad/嘉立创EDA原生工程，未运行ERC，也没有PCB布线或Gerber。这些图适合模块搭建、讨论和设计复核；器件/电源参数冻结后再转成可生产的EDA工程。

## 下一步补齐电源图所需数据

1. 磁芯/取能器完整型号、次级线圈规格、厂家带载曲线，或实验测得的负载扫描。
2. 实验的50Hz一次有效安匝范围，以及次级负载、空载/异常峰值和允许的电压范围。
3. 选用超级电容的容量、耐压、ESR、漏电和充电限制，明确是否需要串联均衡。
4. 无线模组具体版本、配置、整机峰值和平均电流；第一轮可先用仪器模拟负载。

这些数据决定电源器件与保护参数，不需要等主板到货后才开始落实。
